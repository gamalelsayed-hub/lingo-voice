# Lingo Voice

تطبيق أندرويد (Flutter) لتعلم الإنجليزية من كلامك العربي اليومي.

## المميزات

- **اختبار تحديد المستوى**: تقرأ جملة إنجليزية بصوتك وتجاوب على سؤالين مفردات لكل مستوى، والاختبار يتوقف عند أول مستوى صعب عليك. النتيجة من A1 إلى C2، أو تقدر تختار مستواك بنفسك بدون اختبار.
- **الاستماع**: تضغط الزر وتتكلم بالعربي، والتطبيق يحوّل كلامك لنص ويترجمه للإنجليزي على الجهاز نفسه (Google ML Kit).
- **الملخص الذكي (الافتراضي)**: كل 5 دقائق أو عند الإيقاف، يقرأ لك أهم جملك بالإنجليزي بسرعة تناسب مستواك، مع الكلمات الجديدة ومعناها.
- **الترجمة الفورية (اختياري)**: بعد كل جملة تسمع ترجمتها.
- **بطاقات المراجعة الصوتية**: الكلمات اللي تتكرر في كلامك تصير بطاقات بنظام التكرار المتباعد، وفيه وضع "بدون يدين" للمراجعة وأنت ماشي.

## الخصوصية

التطبيق لا يسجّل الصوت. يحوّل الكلام لنص فقط، والبيانات كلها محفوظة على جهازك.

## التثبيت

كل تعديل على `main` يبني ملف APK تلقائياً. حمّله من صفحة [Releases](../../releases/tag/latest) وثبّته على جوالك (فعّل "التثبيت من مصادر غير معروفة").

بعدها التطبيق يفحص التحديثات عند كل فتح، وزر التحديث أعلى الشاشة ينزّل النسخة الجديدة ويفتح شاشة التثبيت.

## التطوير

```bash
flutter pub get
flutter test
flutter run
```

## حدود النسخة الأولى

- التطبيق لا يميّز صوتك عن غيرك، فشغّله وأنت اللي تتكلم.
- أندرويد يوقف الميكروفون بعد كل سكتة، والتطبيق يعيد تشغيله تلقائياً (قد تسمع صوت تنبيه قصير).
- الترجمة حرفية من ML Kit، و"مستواك" يتحكم في اختيار الجمل والكلمات وسرعة النطق وتقسيم الجمل الطويلة.
- التعرف على الكلام يحتاج خدمة Google للتعرف على الصوت في الجوال، وغالباً يحتاج إنترنت.
